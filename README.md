# 密碼旗號生成器 🗺️

> 香港童軍總會 · 筲箕灣區小助手  
> 為童軍活動設計的多功能密碼轉換工具

一個為香港童軍筲箕灣區設計的秘密訊息生成器，支持 13 種不同的密碼轉換方式，每種均配有對照表、全螢幕模式及一鍵複製功能。適合於戶外活動、團隊建設及教學使用。

---

## ✨ 功能特色

- **13 種密碼轉換**：座標密碼、摩斯密碼、凱撒位移、電話密碼、倒序密碼、反射密碼、朱高密碼、旗號、NATO 音標、倉頡、速成、廣東話拼音、普通話拼音
- **每卡均有對照表**：輸入文字時對照表會高亮顯示對應字元
- **全螢幕模式**：每張卡片可獨立全螢幕，顯示放大結果
- **對照表顯示/隱藏**：全螢幕時可隱藏對照表，方便投影演示
- **一鍵複製**：所有結果均可複製到剪貼簿
- **SVG 下載**：朱高密碼與旗號支持下載 SVG 檔案
- **摩斯音訊播放**：可調整速度的摩斯電碼音訊播放
- **完全響應式**：支援手機、平板及桌面螢幕

## 🖼️ 旗號圖片設定

旗號卡片支持顯示自訂圖片（旗號小人）。請將您準備好的 PNG 圖片放入 `images/` 資料夾，檔案命名規則如下：

| 檔案名 | 對應字元 |
|---------|----------|
| `a.png` – `z.png` | A – Z |
| `error.png` | ! (Error) |
| `endof.png` | @ (End) |
| `answering.png` | # (Answering) |
| `attention.png` | $ (Attention) |
| `numbers.png` | % (Numbers) |

> 💡 **提示**：平常模式下顯示對照表；全螢幕模式下顯示旗號小人圖片（若圖片遺失則自動回退為文字顯示）。

### 圖片規格建議
- 格式：PNG 透明背景
- 尺寸：建議 200×200 px 以上
- 風格：統一風格的旗號小人插圖

## 🚀 部署到 Vercel（推薦）

### 方法一：GitHub + Vercel 自動部署（推薦）

1. **Fork 或新建 GitHub Repository**
   - 將此專案的所有檔案推送到您的 GitHub Repository
   - 確保 `index.html`、`css/style.css`、`js/app.js` 都在正確位置

2. **連結 Vercel**
   - 登入 [Vercel](https://vercel.com)
   - 點擊 "Add New Project"
   - 選擇您的 GitHub Repository
   - Vercel 會自動識別為靜態網站（因為存在 `index.html` 在根目錄）

3. **自動部署**
   - 每次推送到 `main` 分支，Vercel 都會自動重新部署
   - 不需要任何建置步驟！

> ⚠️ **重要提醒**：本專案是純靜態 HTML，不需要執行 `npm install` 或任何建置步驟。請確保不要在 Vercel 的專案設定中啟用任何框架或建置命令。

### 方法二：使用 Vercel CLI

```bash
# 安裝 Vercel CLI
npm i -g vercel

# 在專案目錄中登入並部署
vercel login
vercel --prod
```

### 方法三：直接上傳檔案

```bash
# 在專案目錄中執行
vercel --prod
# 選擇 "Other" 作為框架類型
```

## 📚 密碼類型說明

| 密碼 | 描述 | 特色 |
|------|------|------|
| **座標密碼** | 以 5×5 網格將字母轉換為坐標 | 可自訂關鍵字 |
| **摩斯密碼** | 點劃組成的電報編碼 | 支持音訊播放 |
| **凱撒位移** | 字母向後推移 N 位 | 可調整位移量及方向 |
| **電話密碼** | 像傳統電話鍵盤般分組編碼 | 熟悉手機鍵盤的人易上手 |
| **倒序密碼** | 將文字從後到前倒轉 | 最簡單的密碼之一 |
| **反射密碼 (Atbash)** | A→Z, B→Y 的鏡像反轉 | 古希臘密碼 |
| **朱高密碼** | 以符號圖形代替字母 | 支持 SVG 下載 |
| **旗號** | 雙旗手勢代碼 | 可插入自訂旗號小人圖片 |
| **NATO 音標** | 國際民航音標字母 | 通信標準，童軍常用 |
| **倉頡密碼** | 將字母轉換為倉頡字根 | 中文輸入法基礎 |
| **速成密碼** | 簡化版倉頡字根 | 易學易記 |
| **廣東話拼音** | 以粵語讀音代替字母 | 本地化學習 |
| **普通話拼音** | 以普通話讀音代替字母 | 語言學習 |

## 📝 使用提示

1. 輸入英文文字後，所有密碼卡片會實時更新
2. 點擊 **隱藏對照表** 可收起對照表，點擊 **顯示對照表** 可展開
3. 點擊 **全螢幕** 進入放大演示模式
4. 點擊 **複製** 將結果複製到剪貼簿
5. 摩斯密碼支持音訊播放，可調整播放速度
6. 朱高密碼與旗號支持 SVG 下載
