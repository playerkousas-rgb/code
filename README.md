# Scout System 密碼旗號學習平台 🧭

> 香港童軍總會 · 筲箕灣區小助手  
> 集密碼轉換、試卷、電子派卷、互動搶答與遊戲化訓練於一身

這個靜態 Web App 支援 13 種密碼／通訊方式，並內建 Canvas 遊戲化訓練引擎「**密碼防衛戰**」。介面提供**繁體中文／English 雙語切換**，英文版說明見 [README.en.md](README.en.md)。

## 主要模式

### 1. 編碼工具

- 摩斯密碼、旗號、朱高密碼、點字、座標密碼及電話 T9
- 凱撒位移、反射、倒序及 NATO 音標
- 即時轉換、對照表高亮、結果複製、摩斯音訊
- 自動保留未完成訊息草稿

### 2. 試卷生成

- 將工具中的訊息加入題庫
- 每題可選密碼類型、整條／輪播／聲音模式
- **每題獨立設定**：旗號列印樣式（火柴人 / 貝登堡公仔）、輪播速度、方向（翻譯 / 倒轉）
- **倒轉模式**：顯示英文原字，要成員在試卷上自行寫出密碼符號
- 投影播放及 A4 列印；中文標題為「童軍密碼考核試卷」，英文標題為「Scout Cipher Examination」
- **每一頁頁底**固定印出 `© 2026 Scout System · 版權所有 / All rights reserved`；答案紙另加 `CONFIDENTIAL · 領袖專用 / Leaders Only`
- 題目保存在瀏覽器 `localStorage`

### 3. 互動搶答

- 領袖建立 PeerJS 搶答房間及 QR Code
- 成員以手機加入、按鍵或「搖一搖」搶答
- 顯示搶答次序及在線人數

> 搶答模式需要網絡，以載入 PeerJS、QR Code 及建立點對點連線。

### 4. 密碼防衛戰（新增）

前往 `/training/` 即可開始遊戲化訓練：

- 6 種訓練密碼：摩斯、朱高、點字、SCOUT 座標、電話 T9、旗號
- 三段學習路線：
  - **新手學習**：12 題、每次一個目標、四選一、提示及答錯解說
  - **守城任務**：20 題、完整 A–Z 鍵盤及有限血量
  - **無限挑戰**：敵人逐步加速，挑戰最高分
- 四選一干擾答案會優先選用外觀／編碼相近的字母，而非完全隨機
- 答錯後顯示正確答案及符號拆解，並要求再答對才進入下一題
- 自訂速度、血量及限時
- 錯誤字母會跨局增加再次出現的機會
- 每局顯示各密碼準確率、弱項字母及下一步訓練建議
- 保存最高分、上次準確率及完成局數
- 手機提供 A–Z 畫面鍵盤，不會被原生鍵盤遮住遊戲
- 支援觸控震動回饋、音效開關及鍵盤操作
- **遊戲手感／手機沉浸**：Retina 清晰度（devicePixelRatio）、轉 App 自動暫停、答中 hit-stop、分數遞增、連擊能量條、敵人逼近防火牆警告、全螢幕＋螢幕常亮（Wake Lock）、橫向提示
- 設定內可關掉「動感效果」（粒子／震動／閃光），預設跟隨系統 `prefers-reduced-motion`

訓練模式採用內建 Canvas 引擎；遊戲中的旗號以 Canvas 即時繪畫，毋須預載 26 張圖片，減少手機流量。
- **今日任務（練習，唔係挑戰）**：每日 **3 關**，每關**淨係 1 種密碼**、每關 3 題；唔扣血、唔限時、一次只出一題，仲有「📖 對照表」可隨時睇。題目按日期 seeding，同一日重玩都係同一組；完成 +20 ★、連續日數及最佳時間，全部本機紀錄，冇假造全球排行榜
- **三步教法**：首次進入有「HOW TO PLAY · 1/3」，可略過，之後用「？玩法」重開
- **答中解碼揭示**：答啱之後逐個 element 播出 `.- → A` 嘅解碼動畫（可喺設定關掉）

`readme` 知識庫嘅遊戲／動感適用範圍與取捨，見 [`docs/game-feel-reference.md`](docs/game-feel-reference.md)；Astra AI Lab 嘅玩法結構參考見 [`docs/astra-lab-reference.md`](docs/astra-lab-reference.md)；素材與來源見 [`CREDITS.md`](CREDITS.md)。

## 英文版／雙語切換

- 主工具、電子試卷、訓練遊戲三個頁面的右上角都有 **🌐 EN / 🌐 繁** 按鈕；主工具側欄底部亦有一個。
- 切換後會即時翻譯所有介面文字、標題、輸入提示、`aria-label`、投影畫面、試卷題目指示、解碼紙、答案紙，以及由 JavaScript 動態產生的內容（使用 `MutationObserver`）。
- 語言選擇保存在瀏覽器 `localStorage` 的 `skw_ui_lang`，跨頁面、重新整理後仍會保留；亦可在網址加上 `?lang=en` 直接分享英文版連結。
- 譯文集中放在 [`js/i18n.js`](js/i18n.js)。新增介面字串時，把原繁中字串加進 `EN` 對照表即可；含數字／題號的句式用 `PATTERNS` 正則處理。
- 使用者自行輸入的內容（題組名稱、作答、訊息草稿）以 `data-i18n-skip` 標記，永遠不會被翻譯或改寫。
- 版權列是中英對照的固定字串，兩種語言都保持原樣。

## 本機開發

```bash
npm install
npm run dev
```

Vite 會預設開啟主 App；訓練模式位於：

```text
http://localhost:5173/training/
```

## 檢查及建置

```bash
npm test        # 領袖驗證、題組、Worker 模擬及介面流程（Node 22）
npm run check   # HTML 必要元素、重複 ID、JavaScript 語法
npm run lint    # 執行靜態完整性檢查
npm run build   # 同時建置主 App 與 training 多頁入口
```

正式建置會把共用旗號圖片複製到 `dist/images/`，確保兩個入口均能正確載入。

## 部署

專案可直接作為靜態網站部署；目前 `vercel.json` 設為直接輸出專案根目錄。也可執行 `npm run build`，再部署 `dist/`。

## 瀏覽器資料

以下資料只會保存在成員自己的瀏覽器：

- `skw_ui_lang`：介面語言（`zh-Hant` / `en`）
- `skw_message_draft`：編碼草稿
- `skw_test_questions`：試卷題目（含每題的密碼類型、方向、速度、旗號樣式等）
- `skw_cipher_training_settings`：遊戲設定
- `skw_cipher_training_progress`：訓練紀錄（最高分、里程碑、週月排行、歷史折線）
- `skw_cipher_training_achievements`：完美主義徽章（6 密碼 × 3 路徑）

清除瀏覽器網站資料會一併移除以上紀錄。

## 電子試卷與領袖模式

從主頁選「電子試卷」或進入 `/papers/`：領袖可登入後建立最多 50 套題組、從原有試卷匯入、下載私人備份，並分別以固定題目／答案 QR 或 JSON 分享；亦可建立連網活動、手動同步題目與公布答案。每套最多 30 題。固定答案需配合同版本題目，過長時改用 JSON。

成員掃碼、貼連結或匯入檔案，在手機輸入答案，並可下載作答檔交回領袖人工批閱；不會自動上傳成績或評分。旗號和朱高密碼可顯示圖像；反向題的符號答案需以文字描述，現時不支援手繪／圖片交卷。電子試卷座標密碼固定 SCOUT、凱撒位移固定 3；輪播、音訊及投影設定不會從現有試卷匯入。

**連網活動只在成員按「更新題目及答案」時讀取，沒有自動輪詢。** 本機資料和私人備份含答案及活動管理鑰匙，應妥善保管；瀏覽器清除資料後可能遺失。領袖登入最多 24 小時，重新整理或關頁後需重新登入。換密碼無法收回已下載內容；密碼題仍可自行解碼，此功能不適合保護機密或嚴格防作弊。

管理員的完整步驟、費用與私隱注意及驗收清單見 [Cloudflare 電子試卷設定指南](docs/cloudflare-paper-setup.md)。Worker dry-run、模擬 D1／驗證及介面測試已通過；正式 Cloudflare、Vercel、實體手機掃碼及飛航模式仍須按指南驗收。
