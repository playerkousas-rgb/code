❓ 設定說明（3 步搞掂）

  1. 去 supabase.com 開一個免費專案（Free tier 夠晒用）。
  2. Project 開好之後：左邊 SQL Editor → 開新 query → 將 repo 入面 supabase/schema.sql 全部內容貼上去 → Run。 會建立 question_bank、runs 兩個表、RLS 政策同 4 個 RPC。
  3. 左邊 Project Settings → API 抄 Project URL 同 anon public key， 貼返上面「連線設定」，或者寫入 js/cloud-config.js（推薦，全站共用）。

點樣運作

  • 題庫：遊戲每次出題有 60% 機會由雲端題庫抽（其餘用隨機字母）， 並且一樣會優先抽玩家錯過嘅字母。冇網絡就自動用返隨機字母。
  • 排行榜：一局完結會將分數、準確率、破解數、最高連擊、密碼組合、用咗幾耐時間送上去， 每位玩家只計最好嗰局。
  • 防作弊：成績一定要經 submit_run() RPC 寫入，入面檢查分數同破解數係咪合理、 每題至少 200ms、同一個 client 一分鐘最多 10 局、一小時最多 60 局，並做埋限速。
  • 離線：題庫同排行榜都有 localStorage 快取，無網絡時會顯示上次同步嘅內容； 個人紀錄（最高分、里程碑、徽章）一向都係本機計，唔受影響。
  • 唔想開 Supabase 住？ 撳「本機模擬模式」，題庫同排行榜會用 localStorage 模擬， 可以即刻試到成個流程（數據只喺呢部機）。

成本

Supabase Free tier：500MB 資料庫 + 每月 5GB 流量。一個童軍區嘅密碼題庫（幾百題）同幾萬條成績記錄都係零頭，正常唔使畀錢。
